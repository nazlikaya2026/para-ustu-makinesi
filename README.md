# 🪙 Para Üstü Makinesi (Change Calculator)

Bu proje, kullanıcının girdiği alışveriş tutarı ve ödediği miktar üzerinden verilecek *para üstünü en az sayıda banknot ve madeni para* kullanarak hesaplayan bir uygulamadır.

## 🚀 Özellikler
- Girilen tutar ile ödenen miktar arasındaki farkı hesaplar.
- Verilecek para üstünü en büyük banknot/bozuk paradan en küçüğüne doğru optimize ederek en az banknot sayısı ile verir.
